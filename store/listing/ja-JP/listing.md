Melotag

## 短い説明（270 文字以内）

無料でオープンソースの音楽タグエディターです。ソースコードは GitHub で公開されています。タグ、カバー、歌詞、ファイル名を編集でき、まとめて処理することもできます。音声ファイルがコンピューターから離れることはありません。怪しいクラウド事業者や企業が音声を見ることはできません。すべての変更は履歴から復元でき、タグのない曲も音声指紋で識別できます。

## 詳細説明

Melotag は、Windows、Linux、Android に対応するローカル音楽タグエディターです。ダウンロードした楽曲の情報を整えたり、アルバム情報やカバー画像、歌詞をまとめて管理したりするときに役立ちます。ファイルやフォルダーをウィンドウにドラッグするだけで、タイトル、アーティスト、アルバム、アルバムアーティスト、年、トラック、ディスク、ジャンル、コメント、作曲者、歌詞、カバー画像を 1 曲ずつ編集できます。形式、再生時間、ビットレート、サンプルレート、チャンネル、ファイルサイズなどの音声情報も確認できます。保存時には MP3 の ID3v2.3/2.4 を選べ、ファイルの更新日時を保持するか、歌詞をタグに書き込むか、カバー画像を置き換えるか削除するかを指定できます。

Melotag は .NET 10、C#、Avalonia 12 で構築されています。Windows、Linux、Android 版は同じタグ処理コアと UI コードを共有し、ファイル一覧、編集手順、設定項目が各プラットフォームでそろいます。Electron や Chromium のシェルは使わず、画面は Avalonia が描画し、処理は同じ .NET プロセス内で動きます。タグの読み書きは TagLib# によりローカルで完結し、一括マッチ、名前変更、保存の際に音声ファイルをアップロードしないため、複数曲をまとめて整理するときもアップロードを待つ必要はありません。オンラインマッチは必要なときにメタデータ、カバー、歌詞を問い合わせます。Microsoft Store では Windows x64 / arm64 版を提供し、Linux 版と Android 版はプロジェクトの Release から入手できます。

オンラインマッチでは複数の音楽データベースを同時に検索でき、候補のタグ、カバー画像、歌詞を 1 か所で比較できます。結果はドロップダウンで特定のソースだけに絞り込めます。1 曲ずつ結果を選んで適用するほか、一括自動マッチでは取り込むフィールド、使用するオンラインソース、上書き方法を先に指定して、選択した行だけを処理できます。AcoustID の音声指紋を使えば、タグがない、またはファイル名が乱れた曲も音そのものから識別できます。指紋は端末内で計算され、AcoustID には指紋と再生時間だけを送信し、音声ファイルは送信しません。一致したカバー画像は Cover Art Archive から取得します。歌詞パネルでは LRC 歌詞の検索、複数タイムスタンプの整理、タイムタグの削除、空行と先頭タグの削除、オフセット調整、UTF-8／UTF-16／GB18030／Big5 などの文字コードによる読み込みと書き出しに対応します。カバー画像はオンライン検索またはローカルファイルから選択でき、容量、幅、高さ、形式の上限に合わせて自動的に縮小されます。

ファイル名の変更には @0～@8 のフィールドテンプレート、既定の「アーティスト - タイトル」、正規表現のキャプチャグループを使えます。新しいファイル名をプレビューでき、名前が重複する場合は自動で番号が付きます。同名の .lrc とカバー画像を一緒に変更することもでき、ファイル名からタグを書き戻す逆方向モードも利用できます。簡体字・繁体字の変換はタグとファイル名の両方に対応し、同名の .lrc とカバー画像も処理し、ツールメニューからまとめて呼び出せます。ファイル一覧の右クリックメニューでは、選択した行の一括保存、オンラインマッチ、名前変更、タグの消去、削除ができます。列の表示と順序を変更でき、任意の列で並べ替えられ、レイアウトは自動的に記憶されます。保存や名前変更のたびに、変更前のタグのスナップショットがローカルの履歴データベースに保存され、履歴パネルから確認、復元、削除ができます。

UI は日本語、簡体中文、繁體中文、English に対応し、繁体字は簡体字のリソースから実行時に変換されます。初回はシステム言語に合わせて表示され、設定画面からすぐに切り替えられます。ダーク／ライトテーマ、コンパクトな行表示、オンラインソースの順序、検索地域などを変更できるほか、設定画面には各オンラインソースの機能、必要な認証情報、制限を説明する「タグソース紹介」もあります。起動時の更新確認は既定で有効ですが、設定からオフにできます。ヘルプメニューから手動で確認することも可能です。未保存の変更がある状態で終了すると、保存して終了／保存せず終了／キャンセルを確認します。

ご注意：DSF/DFF は認識できますが、実際の DSD サンプルを使った書き込み検証は十分ではありません。複数の音声トラックを含むファイルは処理対象から除外されます。オンラインマッチ、カバー画像、歌詞の結果は、選択した第三者サービスの稼働状況と返却内容に依存するため、情報が不足する場合や一時的に利用できない場合があります。一括変更の前に元ファイルのバックアップを取ることをおすすめします。

## 製品の機能（10 項目）

1. タグ編集と一括操作：タイトル、アーティスト、アルバム、アルバムアーティスト、年、トラック、ディスク、ジャンル、コメント、作曲者、歌詞、カバー画像に対応。MP3 の ID3v2.3/2.4 選択や更新日時の保持も可能。右クリックで選択行の一括保存、マッチ、名前変更、タグ消去、削除ができます。
2. AcoustID 音声指紋：タグのない曲やファイル名が乱れた曲を音から識別。指紋は端末内で計算し、指紋と再生時間だけを送信。カバーは Cover Art Archive から取得します。
3. 複数ソースのオンラインマッチ：NetEase、QQ Music、Kugou、Kuwo、MusicBrainz、AcoustID、Cover Art Archive、iTunes、Last.fm、LRCLIB。結果をソースで絞り込め、一括自動マッチは選択行だけを処理します。
4. 音声情報と対応形式：MP3、FLAC、APE、WavPack、TTA、MPC、OGG、Opus、M4A、MP4、WAV、AIFF、WMA、DSF、DFF を認識し、再生時間、ビットレート、サンプルレート、チャンネル、ファイルサイズを表示します。
5. LRC 歌詞ツール：歌詞検索、複数タイムスタンプの整理、タイムタグや空行・先頭タグの削除、オフセット調整、UTF-8／UTF-16／GB18030／Big5 などでの読み込みと書き出しに対応します。
6. カバー画像管理：オンライン検索、ローカル画像の選択、書き出し、削除、一括抽出に対応。元の画像を保持するか、容量・幅・高さ・形式の上限に合わせて自動縮小するかを選べます。
7. テンプレートと正規表現のリネーム：@0～@8 のフィールド、既定の「アーティスト - タイトル」、正規表現のキャプチャグループを使い、プレビューと重複時の自動採番を提供。同名の .lrc とカバーも一緒に変更できます。
8. ファイル名からタグへ：ファイル名や正規表現から抽出した情報をタグに書き戻し、出所の異なる楽曲の整理に役立ちます。
9. 簡繁変換と繁体字 UI：タグとファイル名を双方向に変換し、同名の .lrc とカバーも処理。UI は簡体中文、繁體中文、日本語、English を切り替えられます。
10. 列設定・履歴・クロスプラットフォーム：列の表示と並べ替えを自由に設定。保存や名前変更の前にタグのスナップショットをローカルデータベースへ記録し、履歴から復元できます。Windows、Linux、Android が共通コアを使用し、ストアは Windows x64 / arm64 版を提供します。

## スクリーンショットのキャプション

- 01-main：メイン画面：ファイル一覧とタグ編集を並べて表示。ファイルやフォルダーをドラッグして追加し、状態や形式、音声情報を確認できます。
- 02-lyrics：歌詞パネル：LRC 歌詞を検索し、タイムタグを整理してプレビュー。歌詞ファイルの読み込みと書き出しも行えます。
- 03-rename：リネーム：テンプレートまたは正規表現で新しいファイル名を生成。重複処理をプレビューし、歌詞とカバーの同時変更も選べます。
- 04-settings：設定：検索、オンラインソース、歌詞、カバー、書き込み、UI のカテゴリ別に整理。言語、テーマ、起動時の更新確認を変更できます。

## 追加のシステム要件

1. Windows 10 バージョン 2004（ビルド 19041）以降、x64 または arm64 プロセッサ。
2. Microsoft Store 版には実行に必要なコンポーネントが含まれているため、.NET ランタイムを別途インストールする必要はありません。
3. オンラインのタグ・カバー・歌詞・指紋検索にはネットワーク接続が必要です。ローカルでの編集と保存はオフラインでも行えます。
4. AcoustID 音声指紋はシステムのデコーダーを使用します。Windows は Media Foundation（Windows N 版はメディア機能パックが必要）、Linux は GStreamer と libav プラグインが必要です。
