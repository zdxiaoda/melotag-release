## 简短标题

音签 Melotag

## 简短说明（不超过 270 字符）

开源且免费的音乐标签编辑器。源代码托管在 GitHub 上。可编辑标签、封面、歌词和文件名，也可批量处理。音频文件永远不会离开电脑；没有糟糕的云服务商或者公司能够看到音频。所有修改都可以从历史记录中恢复，没有标签的文件也能按音频指纹识别。

## 详细说明

音签 Melotag 是一款本地音乐标签编辑器，适合整理下载的音乐、补全专辑信息，以及为本地曲库统一封面与歌词。把文件或文件夹拖入窗口后，可以逐首编辑标题、艺术家、专辑、专辑艺术家、年份、音轨、碟号、流派、注释、作曲、歌词与封面，并查看格式、时长、码率、采样率、声道和文件大小等音频信息。保存时可为 MP3 选择 ID3v2.3/2.4、保留文件修改时间，并决定是否把歌词写入标签、替换或清除封面。

音签 Melotag 使用 .NET 10、C# 与 Avalonia 12 构建。Windows、Linux 和 Android 版本共享同一套标签处理核心与界面代码，文件列表、编辑流程和设置项在各端保持一致。应用不使用 Electron 或 Chromium 外壳，界面由 Avalonia 绘制，逻辑运行在同一个 .NET 进程中。标签读写通过 TagLib# 在本地完成，批量匹配、重命名和保存都不上传音频文件，整理多首曲目时不必等待上传；在线匹配只在需要时查询元数据、封面或歌词。商店提供 Windows x64 / arm64 包，Linux 与 Android 版本可从项目 Release 获取。

在线匹配可同时查询多个音乐数据源，把候选标签、封面与歌词放在同一处比较，并可只查看某个来源的结果；单曲可选择结果后应用，批量自动匹配则可先指定要导入的字段、参与的在线源和覆盖方式，并且只处理选中的行。AcoustID 音频指纹识别可按声音内容认出没有标签或文件名错乱的文件：指纹在本地计算，只把指纹与时长发送给 AcoustID，不上传音频；匹配到的封面通过 Cover Art Archive 获取。歌词面板支持搜索 LRC 歌词、整理多时间戳、移除时间标签、删除空行与头部标签、整体偏移，以及按 UTF-8、UTF-16、GB18030、Big5 等编码导入和导出。封面工具可在线查找或从本地选择图片，并按体积、宽高和格式限制自动缩放。

重命名支持 @0–@8 字段模板、默认“歌手 - 歌名”规则和正则捕获组，提供实时预览与重名自动编号，也能连带处理同名 .lrc 与封面文件；反向模式可根据文件名写回标签。简繁转换覆盖标签与文件名，并可同步处理同名 .lrc 与封面，工具菜单提供集中入口。主列表的右键菜单可对选中的一首或多首批量保存、在线匹配、重命名、清除标签或移除；列可自定义显示与顺序、按任意列排序，布局和排序会自动记住。历史面板则把每次保存或重命名前的标签快照存入本地数据库，可随时查看、恢复或清空。

界面提供简体中文、繁體中文、日本語和 English，繁体界面由简中资源实时转换，默认跟随系统并可即时切换；深色/浅色主题、紧凑行高、在线源排序和搜索地区等选项都在设置中，设置页还提供标签源介绍，说明各在线源的能力、凭据与限制。启动时会静默检查新版本，也可在帮助菜单手动检查，并可在设置中关闭。有未保存修改时退出会提示保存并退出、不保存退出或取消。

说明：DSF/DFF 文件可以识别，但写入尚未用真实 DSD 样本充分验证；包含多音轨的音频文件会被跳过。在线匹配、封面和歌词结果取决于所选第三方服务的可用性与返回内容，可能不完整或暂时不可用。建议在批量修改前保留原始文件备份。

## 产品功能（10 条）

1. 逐首与批量标签编辑：标题、艺术家、专辑、专辑艺术家、年份、音轨、碟号、流派、注释、作曲、歌词与封面；MP3 可选 ID3v2.3/2.4 并保留文件修改时间；右键菜单可对选中行批量处理。
2. AcoustID 音频指纹：无标签或文件名错乱时按声音内容匹配，指纹在本地计算，只发送指纹与时长；结果可关联 Cover Art Archive 封面。
3. 多源在线匹配：网易云、QQ 音乐、酷狗、酷我、MusicBrainz、AcoustID、Cover Art Archive、iTunes、Last.fm 与 LRCLIB；结果可按来源筛选，批量自动匹配只处理选中行。
4. 音频信息与格式：识别 MP3、FLAC、APE、WavPack、TTA、MPC、OGG、Opus、M4A、MP4、WAV、AIFF、WMA、DSF 与 DFF，显示时长、码率、采样率、声道和大小。
5. LRC 歌词工具：搜索歌词，整理多时间戳，移除时间标签、空行和头部标签，整体偏移，并按 UTF-8、UTF-16、GB18030、Big5 等编码导入导出。
6. 封面管理：在线查找、本地选择、导出、移除与批量提取；可选保留原始封面，或按体积、宽高和格式上限自动等比缩放，保存时写回标签。
7. 模板与正则重命名：使用 @0–@8 字段、默认“歌手 - 歌名”或正则捕获组，实时预览并按重名自动编号；可连带重命名 .lrc 与封面。
8. 文件名写回标签：反向模式下从文件名或正则表达式提取信息并写入标签，适合整理命名规则不一的曲库。
9. 简繁转换与繁体界面：标签与文件名支持简转繁、繁转简，并可同步处理同名 .lrc 与封面；界面可切换简体中文、繁體中文、日本語与 English。
10. 列表、历史与跨平台：列可自定义显示与顺序、按任意列排序；每次保存或重命名前把标签快照写入本地数据库，可查看、恢复或清空；Windows、Linux 与 Android 共用核心，商店提供 Windows x64 / arm64 包。

## 附加系统要求

1. Windows 10 版本 2004（内部版本 19041）或更高版本；x64 或 arm64 处理器。
2. Microsoft Store 安装包已包含运行所需组件，无需单独安装 .NET 运行时。
3. 在线标签、封面、歌词与指纹查询需要网络连接；本地编辑与保存可离线完成。
4. AcoustID 音频指纹识别使用系统解码组件：Windows 使用 Media Foundation，Windows N 版需安装“媒体功能包”；Linux 版需安装 GStreamer 及 libav 解码插件。
