音签 Melotag 安装说明
=====================

跨平台音乐标签编辑器。

启动方式
--------
从开始菜单或桌面快捷方式启动 Melotag。
本安装包已包含 .NET 运行时，无需另外安装。

音频指纹识别
------------
AcoustID 指纹识别使用 Windows Media Foundation 解码音频。
Windows N 版默认不含媒体组件，如该功能不可用，请安装“媒体功能包”
（Media Feature Pack）。

数据目录
--------
%APPDATA%\Melotag
可用环境变量 MELOTAG_DATA_DIR 覆盖。

网络
----
在线标签匹配、封面、歌词与指纹查询需要网络连接；
本地编辑与保存可离线完成。

卸载
----
设置 → 应用 → 已安装的应用 → 音签 Melotag → 卸载。
